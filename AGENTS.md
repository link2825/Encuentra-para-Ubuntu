# Instrucciones para Codex

## Recuperación ante errores repetitivos

Si dos intentos de corrección del mismo problema fallan:

1. No repetir soluciones sin evidencia nueva.
2. Revisar errores, registros, pruebas y diferencias reales del código.
3. Identificar hipótesis incorrectas y contradicciones.
4. Conservar modificaciones funcionales y evitar cambios innecesarios.
5. Si el contexto dificulta continuar, recomendar una sesión nueva y preparar un informe de continuidad con objetivos, entorno, estado Git, archivos modificados, pruebas realizadas, fallos y siguiente paso.
6. No descartar avances válidos ni reiniciar el proyecto.
7. No realizar commits, push ni cambios destructivos sin autorización explícita.
